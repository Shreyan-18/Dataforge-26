Architectural Breakdown: Why Synapses Beat the Cache

In standard Transformers, processing long context requires saving every key and value vector into the Key-Value (KV) Cache. For an 8B parameter model at 128k context, this cache can consume over 16 GB of VRAM per user, causing latency and cost to balloon quadratically during generation.

Dragon Hatchling (BDH) replaces this growing token buffer with an evolving biological principle: synaptic plasticity. Instead of storing tokens, the model updates a fixed-dimension connection matrix Wt ∈ ℝd × d using a local Hebbian rule: "neurons that fire together, wire together".
